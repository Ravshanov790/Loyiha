# MindQuest 3D MVP Prototype

Bu repository hozircha MindQuest 3D uchun premium frontend MVP prototype’ni o‘z ichiga oladi.

## Ichidagilar
- `index.html` — landing + dashboard + key systems showcase
- `styles.css` — premium dark gaming/SaaS visual system
- `app.js` — oddiy interaktiv case opening demo
- `docs/mindquest-3d-product-blueprint.md` — to‘liq product blueprint

## Ishga tushirish
Statik loyiha, shuning uchun local server bilan ochish tavsiya etiladi.

### Python orqali
```bash
python3 -m http.server 3000
```

Keyin brauzerda `http://localhost:3000` ni oching.
